# Геометрия в пространстве

Два интерактивных решения задач по стереометрии для 10 класса.

- [Все задачи](https://azabolo.github.io/anatomy-geometry-demos/)
- [Задача 29: трапеция и плоскость](https://azabolo.github.io/anatomy-geometry-demos/anatomy-task29-demo/)
- [Треугольник и параллельная плоскость](https://azabolo.github.io/anatomy-geometry-demos/anatomy-triangle-plane-demo/)

## Возможности

Вращение трёхмерного чертежа мышью и пальцем, масштабирование,
перемещение точек, переключение ракурса, плоский вид и пошаговое решение.
Светлая и тёмная темы, компактная компоновка и полное доказательство.

В задаче 29 доказывается пересечение плоскости ADK с MC и получается KH = 6 см.
Во второй задаче из параллельности плоскости основанию и подобия треугольников
получается M₁K₁ = 18 · 5/12 = 7,5 см.

Каждая страница автономна: HTML, CSS и JavaScript включены в один файл.
Серверная логика, внешние библиотеки и установка npm-пакетов не требуются.

## Локальный запуск

Можно открыть корневой `index.html` напрямую в браузере или запустить
статический сервер из этой папки:

```sh
python3 -m http.server 8000
```

## Сборка

Для изменения исходников нужен Node.js. После правок выполните:

```sh
node build.mjs
```

Команда пересобирает обе задачи, светлые и тёмные версии и страницу каталога.
Сгенерированные HTML-файлы хранятся в репозитории.

## Проверка математики и камеры

```sh
node --test anatomy-task29-demo/model.test.mjs anatomy-task29-demo/camera.test.mjs
node --test anatomy-triangle-plane-demo/model.test.mjs anatomy-triangle-plane-demo/camera.test.mjs
```

## GitHub Pages

выдачу готовых статических файлов без обработки Jekyll.
